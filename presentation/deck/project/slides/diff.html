[시간] 약 40초 [대본] 비슷한 서비스가 없었던 건 아닙니다. 채록이나 MapDreamy 같은 '지도 저장형'은 릴스를 공유하면 AI가 장소를 뽑아 지도에 핀을 꽂아 줍니다. 하지만 결국 사용자가 "오늘 뭐 먹지?" 하고 앱을 직접 열어야 가치가 생깁니다. Stash 같은 북마크 앱은 알림을 보내 주지만, 매일 몇 시처럼 정해진 시간 기준이라 내가 어디 있는지는 모릅니다. 애플 미리 알림 같은 앱은 위치 알림이 되지만, 장소와 조건을 사람이 직접 입력해야 합니다. REMEMBRALL은 공유 한 번으로 장소를 자동으로 정리하고, 앱을 열지 않아도 근처에 가면 먼저 꺼내 줍니다. 그리고 그때 AI가 보낼지 말지를 판단합니다. 아래 두 줄, 근처 도착 알림과 AI 판단을 함께 하는 서비스는 저희가 조사한 범위에서는 없었습니다. [표 근거] - 미리 알림(Apple 미리 알림 / Google Keep / TickTick): 링크는 URL 첨부만(△), 위치 도착 알림은 가능하지만 장소를 직접 입력(△). - Stash: SNS 링크 저장 + 지정 요일·시간 리마인드, 지도 링크 저장 시 현재 위치로부터 거리 표시(근처 도착 알림은 아님 → X). - RemindLink도 Stash와 같은 '시간 기반 리마인더' 부류(표에서는 생략). - Plotline / Triply / Pintra(글로벌)는 채록·MapDreamy와 같은 '지도 저장형' 부류(영상 텍스트·오디오·캡션 분석 → 지도 매핑, 카테고리 자동 분류). - MapDreamy는 저장 장소로 여행 동선·캘린더 생성 기능도 있음(알림은 아님). [차별화 핵심] 1. 컨텍스트 인지형 리마인드: 앱을 켜지 않아도 근처에 가면(지오펜싱) 선제적 알림 → '저장 후 방치'를 가장 근본적으로 해결. 2. 알림 품질: 단순 근접 알림이 아니라 AI 판단(날씨·영업·알림 무시 이력)으로 스팸이 되지 않게. (+ 로드맵) 공간(맛집 → 지도)과 시간(축제·팝업 → 캘린더) 분기는 기존 서비스들이 장소 하나에만 집중하는 것과 다른 확장 방향. [주의] - "없다"는 단정 대신 "조사한 범위에서는"이라고 말하는 걸 권장합니다. - 경쟁사 로고는 넣지 않았습니다(상표 문제). 필요하면 이름만으로 충분합니다.
