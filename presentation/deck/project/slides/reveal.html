REMEMBRALL

잊은 장소를, 근처에서 다시
[시간] 약 25초 [대본] 그래서 저희는 REMEMBRALL을 만들었습니다. 저장만 해두고 잊어버린 곳을, 그 근처에 갔을 때 AI가 먼저 꺼내주는 앱입니다. 사용자가 할 일은 평소처럼 숏폼을 보다가 '공유' 버튼을 한 번 누르는 것뿐입니다. 정리도, 기억도 REMEMBRALL이 대신합니다. [연출 메모 — 왜 여기서 색이 돌아오는가] - 앞 장표들은 흑백 = 잊혀서 바랜 기억. 이 장부터 앱의 실제 색(아이보리 #F6F1EE, 자두색 #6B4E7A)이 돌아옵니다. - 앱 디자인 콘셉트가 "바랜 기억"입니다. 저장한 지 오래된 영상일수록 썸네일이 바래고(오늘 0% → 3주 30% → 5개월 50%), 근처에 오면 원래 색으로 되살아납니다. - 로고 모션 「떠오르는 계단」: 흐린 뒷장들이 차례로 들렸다가(기억을 뒤적이는 중) 맨 앞장이 "뾱" 하고 골라지는 동작. 앱 실행 화면과 같은 타이밍입니다. - 제목과 문구는 발표 모드에서 순서대로 떠오릅니다. [한 줄 정의(필요 시)] "저장만 해두고 잊어버리는 숏폼 북마크 문제를, AI 장소 추출과 위치 기반 알림으로 해결하는 능동형 아카이빙 비서."
