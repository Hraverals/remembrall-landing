■ 이 장의 역할 - 시연 영상 재생 자리(링크 예정) ■ 영상에 담을 장면 후보 (순서) 1. 유튜브 대전 맛집 쇼츠 → 공유 → REMEMBRALL → '저장했어요' 시트 → '돌아가기'로 유튜브 복귀 2. 기억 탭: 방금 저장한 영상 '분석 중' → 장소 확정 3. 애매한 영상: "이 영상, 어디였을까요?" 되묻기 → 후보 선택 (또는 '여기 없어요, 직접 찾을게요') 4. 근처 탭 / 지도 탭: 저장한 곳이 썸네일 핀으로 5. 근처 도착 → 잠금화면 알림 "3주 전에 저장한 빵집이 도보 4분 거리에 있어요" → 탭하면 장소 상세 6. 기억 탭: 오래된 썸네일이 바래 있는 모습 - 권장 길이: 10분 발표 기준 1분 30초~2분 ■ 시연 안전장치 (Notion UX 강조점) - 목(mock) 모드: 서버 없이 전체 흐름(분석 딜레이, 되묻기, 알림)을 실제처럼 재현 - 가짜 알림도 실제 알림과 같은 코드 경로로 열림 - 네트워크 끊김·분석 실패 같은 에러 상황을 강제 재현 가능 → 시연 리스크 최소화 - 서버 없이 시연하는 preview-mock APK 빌드 있음 - 시연 도구(연결 상태 표시줄): 서버 연결 / 목 모드 / FCM 상태를 한눈에 확인 — '운영까지 신경 썼다'는 과정 언급용 - 설정 맨 아래에서 FCM·지오펜스 상태 확인, "{장소}에 도착" 가상 도착 이벤트 전송 가능 → 실제 장소에 가지 않아도 알림 흐름 시연 ■ 언급 포인트 - 실제 장소에 갈 수 없는 발표 환경에서 가상 도착 이벤트로 실제와 같은 경로의 알림을 띄움 ■ 시간 - 영상 길이에 따라
