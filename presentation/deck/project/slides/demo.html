시연 영상

[시간] 영상 길이에 따라 (10분 발표면 1분 30초~2분 권장) [대본 — 영상 틀기 전] 그럼 실제로 동작하는 모습을 보여드리겠습니다. [시연 순서 제안 — 영상 촬영·편집용] 1. 유튜브에서 대전 맛집 쇼츠 시청 → 공유 → REMEMBRALL → "저장했어요" 시트 → '돌아가기'로 유튜브 복귀 2. 기억 탭: 방금 저장한 영상 '분석 중' → 잠시 뒤 장소 확정 3. (애매한 영상) "이 영상, 어디였을까요?" 되묻기 → 후보 선택 4. 근처 탭 / 지도 탭: 저장한 곳이 썸네일 핀으로 5. 근처 도착 → 잠금화면 알림 "3주 전에 저장한 빵집이 도보 4분 거리에 있어요" → 탭하면 장소 상세 6. (선택) 기억 탭에서 오래된 썸네일이 바래 있는 모습 [시연 안전장치 — Notion UX 강조점, 한 줄 언급용] - 목(mock) 모드: 서버 없이도 전체 흐름(분석 딜레이, 되묻기, 알림)을 실제처럼 재현. 가짜 알림도 실제 알림과 같은 코드 경로로 열리고, 네트워크 끊김·분석 실패 같은 에러도 강제로 재현 가능. 서버 없이 시연하는 preview-mock APK 있음. - 시연 도구(연결 상태 표시줄): 서버 연결 / 목 모드 / FCM 상태를 한눈에 확인. 설정 맨 아래에서 "{장소}에 도착" 가상 도착 이벤트를 보내 실제로 가지 않아도 알림 흐름을 보여줄 수 있음. - 멘트 예: "실제 장소에 갈 수 없어서, 시연 도구로 도착 이벤트를 보내 실제와 같은 경로로 알림을 띄웠습니다." → '운영까지 신경 썼다'는 과정 언급.
