[시간] 약 30초 [대본] 저장한 장소는 세 가지 방식으로 다시 만납니다. '근처' 탭은 지금 내 위치에서 가까운 저장 장소를 보여줍니다. 장소 이름보다 "3주 전"처럼 언제 저장했는지가 더 크게 보이는데, 잊고 있던 기억을 다시 떠올리게 하는 게 이 앱의 목적이기 때문입니다. '지도' 탭에서는 저장한 곳이 영상 썸네일 핀으로 찍혀 있고, 핀을 누르면 상세로 이어집니다. 상세 화면에는 영상에서 저장해 둔 메모와 태그, 원본 영상으로 돌아가는 링크가 있습니다. [세부 사실 — 질문 대비] - 하단 탭: 근처 · 지도 · 기억 (설정은 헤더 톱니). - 지도: Google Maps SDK(react-native-maps) + Figma 색 토큰 커스텀 스타일. 핀과 겹치는 가게·교통·도로 라벨 숨김. 썸네일 핀, 오래된 기억일수록 핀이 작아짐(40 → 26 → 22). - 상세: 바텀시트(기본/펼침). 메모·태그·위치 권한이 없으면 해당 줄 숨김. - "이 장소가 아니에요" → 직접 찾기로 장소 변경 가능. - "길 안내 시작" 버튼은 디자인만 있고 경로 API 연결 전(로드맵). - 헤딩 서체 Gowun Dodum(앨범에 손으로 적은 캡션 같은 온기), 본문 Noto Sans KR.
