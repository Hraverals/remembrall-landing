■ 이 장의 역할 - 이전 5번(즉시 행동 vs 나중에)과 6번(저장 후 방치)을 한 장으로 합침. "97%는 나중에 본다고 하지만, 실제로는 85%가 안 본다" - 두 수치는 서로 다른 조사(픽플리 / Rana·Media Tsundoku)라 "97% 중 85%"처럼 이어서 말하지 말 것 ■ 화면 구성 - 왼쪽(회색): 나중에 확인 97%, 즉시 행동 8.4% / 가운데: 85% 다시 열지 않음 / 오른쪽: 100칸 격자(진한 15칸 = 다시 봄, 연한 85칸 = 방치) ■ 핵심 수치와 출처 - 숏폼으로 유용한 정보를 얻고 즉시 행동(방문·구매)으로 옮기는 비율 8.4%, 나중에 다시 확인하는 과정을 거치는 비율 97% (별개 문항, 합이 100%가 아님) — 픽플리, 숏폼 콘텐츠 마케팅 소비자 경험 리포트(2026.04) - 소셜 플랫폼(인스타·틱톡·유튜브) 전반의 저장 → 실제 재열람 전환율(Saved-to-viewed) 15% 미만 = 85% 이상 방치 (추산) — Rana, 「Why users save content but never revisit it」(Medium Product Research, 2026.04). '귀환 시스템(Return System)'의 부재를 원인으로 지적 - 나중에 보기(Read-it-later)·북마크 앱 실측: 저장 콘텐츠의 83%는 끝내 소비되지 않음, 헤비 유저일수록 재열람률 12%까지 하락, 북마크의 65~88% 미열람 — Media Tsundoku (Mozilla Pocket 등 인용) ■ 해석 포인트 - 저장은 "나중에 가겠다"는 약속. 그런데 그 '나중'은 대부분 오지 않는다 - 100개 저장 → 85개는 다시 안 열림. 격자의 흐려지는 칸 = 앱 디자인 '바랜 기억'과 같은 은유 ■ 주의 - 추산·인용 데이터 → "약 85%", "10개 중 8개 이상"처럼 범위로 말하는 게 안전 ■ 시간 - 약 30초
