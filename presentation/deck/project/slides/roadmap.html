[시간] 약 35초 [대본] 지금 MVP는 '장소를 기억하는' 단계입니다. 유튜브 쇼츠를 저장하고, 장소를 확정하고, 근처에 가면 꺼내 줍니다. 다음은 '시간도 기억하는' 단계입니다. 축제나 팝업스토어처럼 기간이 정해진 콘텐츠는 지도 대신 캘린더로 보내서, 날짜가 다가오면 알려 주려고 합니다. 영상에서 기간 정보는 이미 추출하고 있어서 트리거로 연결하는 일만 남았습니다. 인스타그램 릴스, 카카오 로그인, iOS도 이 단계입니다. 그다음은 '함께 기억하는' 단계입니다. 사용자가 동의한 저장물을 다른 사용자의 추천 후보로 쓰고, 그 위에서 수익 모델을 만들 수 있습니다. [세부 사실 — 질문 대비] - MVP 범위(docs/카테켐프로젝트 개요.md): YouTube Shorts, 장소 추출·검증, 위치 트리거. 일정 트리거와 Instagram은 명시적으로 제외. - 기간 정보: 분석 결과에 기간 정보(TemporalInfoDto)가 이미 포함, 트리거 미연결. 장소 카테고리에서 '축제'를 제외한 이유 = 시간 트리거 대상. - 카카오 로그인: 디자인·서버 구조 준비 완료(비활성). MVP는 설치 ID 기반 게스트 세션. - iOS: 지오펜스 설계는 iOS 한도(20개) 기준, 현재 빌드는 Android 전용. - 공용 풀: 에이전트의 searchCandidates가 이미 개인/공용 범위를 구분해 검색하도록 설계. 공용 후보의 저장 관계 비노출이 평가 필수 조건. - 길 안내: 상세 화면 버튼은 디자인만, 경로 API 연결 전. - 기술 로드맵(질문 시): 장소 단위 쿨다운, 필요 시 LangGraph4j 재검토, 트래픽 증가 시 벡터 검색 분리(ADR001에 조건 명시).
